# Карта вопросов Валерии Фридлендер

Интерактивный дизайн-прототип сайта персональных разборов через астрологию,
нумерологию и цифровую психологию.

## Ссылки

- Сайт: https://ivashkov2022-droid.github.io/valeria-fridlender-question-map/
- Открытый репозиторий: https://github.com/ivashkov2022-droid/valeria-fridlender-question-map
- Основной закрытый репозиторий: https://github.com/ivashkov2022-droid/valeria-fridlender-question-map-source

## Локальная работа

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

## Проверка и публикация

```bash
npm run build
npm run build:pages
```

- `app/` — исходники основной версии сайта.
- `public/` — фотографии и служебные изображения.
- `docs/` — готовая статическая сборка для GitHub Pages.

Формы в текущем прототипе демонстрируют пользовательский сценарий и не
отправляют введённые данные.
